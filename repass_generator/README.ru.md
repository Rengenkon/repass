# repass_generator

[English documentation](README.md) | Документация на русском

`repass_generator` — крейт на Rust для генерации паролей из словарей. Он поддерживает точную длину и диапазон длин, Unicode-элементы, разные правила расстановки разделителей, а также генерацию одного или нескольких паролей.

## Быстрый старт

```rust
use repass_generator::dictionary::{cache::DictionaryCache, file_dictionary::FileDictionary};
use repass_generator::generator::generate_once;
use repass_generator::query::{PasswordLength, Query};
use repass_generator::separator::between_parts::BetweenPartsSeparator;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let dictionary = FileDictionary::from_entries(["river", "silver", "forest"])?;
    let dictionary = DictionaryCache::new(dictionary)?;
    let separator = BetweenPartsSeparator::new("-");
    let query = Query::new(
        PasswordLength::Range {
            min_chars: 12,
            max_chars: 20,
        },
        &dictionary,
        &separator,
    )?;

    let password = generate_once(&query)?;
    println!("{password}");
    Ok(())
}
```

Длина результата считается в Unicode scalar values через `str::chars().count()`, а не в байтах или графемных кластерах.

## Основные понятия

### Словарь (`Dictionary`)

`Dictionary` предоставляет непустые строки, которые генератор может выбирать. Элементом может быть буква, слово или любая другая строка. В крейте есть:

- `FileDictionary` — принадлежащий объекту список строк, который можно загрузить из UTF-8-текстового файла или сохранить в него; одна строка файла соответствует одному элементу.
- `PresetDictionary` — встроенные наборы символов: цифры, буквы, знаки пунктуации и другие символы. К ним можно добавлять пользовательские элементы.
- `DictionaryCache` — проверенный и проиндексированный словарь, сгруппированный по длине элементов. Сначала завершите изменение словаря, затем создайте кэш; после этого словарь не следует менять.

Пустые словари и пустые элементы недопустимы. API словаря также отклоняет повторное добавление одинаковых элементов.

### Запрос и длина

`Query` объединяет `PasswordLength`, `DictionaryCache`, `Separator` и `GenerationLimits`. При создании проверяются длина, словарь и разделитель.

`PasswordLength::Exact(n)` задаёт точное число символов `n`. `PasswordLength::Range { min_chars, max_chars }` позволяет генератору случайно выбрать целевую длину включительно в указанном диапазоне. По умолчанию используется диапазон от 12 до 20 символов.

`GenerationLimits` ограничивает число проверяемых схем разделения и состояний планировщика. Значение по умолчанию для каждого ограничения — 100 000. При достижении лимита генерация завершится с ошибкой, а не будет искать бесконечно.

### Разделители

Трейт `Separator` задаёт способ объединения выбранных элементов и вычисляет длину результата.

| Стратегия | Поведение |
| --- | --- |
| `WithoutSeparator` | Объединяет элементы без дополнительных символов. |
| `BetweenPartsSeparator` | Вставляет строку между каждой соседней парой элементов. |
| `FixedIntervalSeparator` | Вставляет строку через заданные интервалы символов содержимого. |
| `FixedCountSeparator` | Распределяет заданное число разделителей по содержимому. |

Разделитель может состоять из нескольких Unicode scalar values. У стратегий с настройкой по умолчанию разделитель равен `-`.

### Формы и подбор комбинации

`SeparationShape` описывает длину содержимого и число элементов словаря, подходящие для целевой длины с учётом стратегии разделения. Разделитель выдаёт возможные формы по мере необходимости. Затем внутренний планировщик комбинаций ищет элементы словаря с подходящими длинами, а разделитель собирает из них строку.

Такое разделение обязанностей позволяет учитывать символы-разделители при соблюдении точной длины результата.

## Генерация нескольких паролей

Для генерации нескольких паролей используйте `generate_multi(query, count)`. Для воспроизводимого результата, например в тестах, используйте `generate_once_with_rng` или `generate_multi_with_rng` и передайте свой генератор случайных чисел (RNG).

## Ошибки и ограничения

Функции генерации возвращают `Result` и сообщают о некорректной длине, словаре или разделителе, невозможной целевой длине, отсутствии подходящей комбинации словаря, а также о достижении ресурсных и поисковых лимитов. Даже корректный запрос не гарантирует, что выбранные словарь и разделитель позволяют получить результат каждой запрошенной длины.

## Тезаурус

| Термин в API | Значение | Понятные синонимы |
| --- | --- | --- |
| Dictionary entry | Один выбираемый элемент словаря | запись, значение, слово, фрагмент |
| Dictionary cache | Словарь с индексом по длинам для генерации | кэш, индекс, таблица поиска, подготовленный словарь |
| Query | Полная конфигурация генерации | запрос, спецификация, параметры |
| Target length | Требуемое количество символов результата | целевая длина, размер вывода |
| Content length | Длина содержимого без вставленных разделителей | длина основы, длина полезного содержимого |
| Part | Один выбранный элемент словаря в результате | часть, сегмент, компонент, фрагмент |
| Separation shape | Длина содержимого и число частей для возможного результата | схема, раскладка, шаблон, вариант компоновки |
| Separator | Правило добавления строк-разделителей или их пропуска | стратегия разделения, правило склейки, форматирование |
| Planner state | Промежуточное состояние поиска комбинации | состояние поиска, узел поиска, вариант подбора |
| Generation limit | Верхняя граница вычислительной работы поиска | лимит, бюджет поиска, ограничение |
